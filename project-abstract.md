# Project Abstract

## Title
Student Record Management System using C

## Abstract
The Student Record Management System is a menu-driven console application developed in the C programming language. It is designed to make basic student-record operations easier by allowing a user to add, view, search, update, and delete student information.

The program uses a structure to represent each student and binary file handling to save records locally. Because records are stored in a file, they remain available after the program is closed and started again.

## Objectives
- Provide a simple way to maintain student records.
- Demonstrate structures and modular programming in C.
- Demonstrate persistent storage through file handling.
- Support basic record operations.

## Tools and Technologies
- Language: C
- Compiler: GCC or another standard C compiler
- Storage: Local binary file

## Modules
1. Add student
2. View students
3. Search student
4. Update student
5. Delete student

## Conclusion
This project demonstrates how C programming concepts can be combined to build a basic record-management application. It can be extended with authentication, sorting, report generation, and a database.
